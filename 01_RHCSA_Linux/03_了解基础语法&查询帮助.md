# Linux命令语法

- Linux命令语法的构成:三要素-->命令、选项、参数
  - 选项:对命令这个功能的补充(比如`Is-1`，显示详细的信息)
  - 参数:你的命令对哪个对象操作(可以是用户，可以是目录，可以是文件等)命令后面可以不需要接上选项以及参数，但不是所有的命令都支持
  - 命令:实现一个特定的功能(比如`useradd`创建用户，`Is`列出目录下内容，`pwd`输出当前的工作目录)
    `选项都是以为-或者--开头的，-是选项的段格式，--是选项的长格式`
    `短格式的选项是长格式选项的缩写，但不是所有长格式都有短格式`

- 命令、选项、参数之间使用空格隔开
  `命令和选项(ls-I)`
  `选项和选项(Is-I-a)`
  `选项和参数(Is-|/root)`
  `参数和参数(Is/root/boot)`
  `除此之外，短格式选项是支持连写的。比如ls-a-I可以写成Is-al`

# 如何查询Linux的帮助

**`whatis`** 

`nothing appropriate.`时需要执行命令`mandb`生成索引 实际是查询man手册的内容所以`whatis=man -f`

**`-help`**
查询命令本身的帮助，可以查看到命令的格式、支持的选项、语法

**Usage: ls [OPTION]... [FILE]...**

- ```
  `[]  `表示是可选项
   
   `... `表示列表，可以支持接多个内容
   
    大写字母表示是必选项
   
   `+FORMAT`表示特定的格 式
  
   ` a|b|c `表示多选一
    
    `< >`表示有默认的值
  
   `[MMDDhhmm[[cc]YY][.ss]`特殊格式
  ```

  

**`info / pinfo`**
`info`查询是根据命令的分类进行查询，比如说命令的选项、命令的格式、命令支持的功能等

**`man手册`**
man手册记录着系统大量的帮助，比如命令的帮助、文件的帮助等等等

常用命令 `man -f` `man -k` `man 章节名 关键字`

目录:`/usr/share/man`
**man手册标准章节** 

```
1.用户的命令

2.系统的函数库

3.系统内核调用的函数

4.特殊设备文件

5.文件的格式

6.游戏

7.软件包和其他的帮助

8.root用户的命令

9.系统内核的信息
```

**常用:**
**·1用户命令**
**·5文件格式**
**·8系统管理命令**

**`/usr/share/doc`**
`此目录保存着软件的帮助文档，比如下载了一个Vsftpd的软件，那么只要是自定义下载的软件，软件的默认帮助文档就保存到这个目录。`
