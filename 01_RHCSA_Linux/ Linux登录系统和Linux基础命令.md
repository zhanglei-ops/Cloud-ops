# Linux登录系统和Linux基础命令

## 1. Linux登录系统的方式

- **桌面图形化登录**

- **字符界面登录**

  > 不管你是通过图形化登录还是字符页面登录，都是基于 Linux 的虚拟控制台来实现登录的。

  - 虚拟控制台和图形控制台：
    - `F1-F6` 对应 6 个不同的虚拟控制台。
    - `F1-F2` 都是图形化的虚拟控制台，并且 F1 永远是图形化的登录页面。
    - 切换虚拟控制台快捷键：`Ctrl + Alt + F[1-6]`。
    - *注意：按组合键没有效果，尝试加上一个 `Fn` 键。*

- **通过浏览器登录 (Cockpit)**

  ```bash
  # 启动 cockpit 服务并设置开机自启
  systemctl enable --now cockpit.socket
  
  # 获取虚拟机 IP 地址
  ip addr   # 推荐使用 (RHEL 9 默认自带)
  ifconfig  # 备用 (需要先安装 net-tools 包)
  ```

- **物理机和虚拟机的通信**：
  - 在物理机 CMD 命令行测试连通性：输入 `ping 虚拟机IP地址`。
  - 在物理机浏览器访问：输入 `https://虚拟机IP地址:9090`。

## 认识命令行和命令基础使用



**`[root@node ~]# `**命令提示符

```
#：表示特权提示符。当前用户是 root 用户显示 #，普通用户显示 $。
~：表示当前所在的工作目录。~ 代表当前用户的家目录（root 用户在 /root 下）。
node：表示当前系统的主机名（短格式）。
@：表示用户和主机名之间的分隔符号。
root：表示当前登录的用户。
```

**`useradd` **: 创建用户 useradd 用户名

**`pwd`**：打印当前所在的工作目录

**`ls`**：列出当前或者指定目录下的内容

**`date`**：显示日期

**`cal`** ：查看当前日历

**`id`**：查看用户的简略信息

**`vim`** :文本编辑器

```
1.格式：vim 文件名
2.如果打开的是一个不存在的文件-->保存后会创建一个空的文件
3.如果打开的是一个存在的文件，则可以看到文件的内容并且可以修改
4.使用vim修改文件的一个步骤:
  vim 打开一个文件
    按‘i’切换到insert 编辑模式
      修改内容
        按'ecs’退出insert模式
          按'shift+:’
            然后输入wq 保存并且退出
```

**`passwd`**：修改用户密码

```
1.格式:passwd用户名
2.只有root用户才可以给其他用户修改密码，并且修改密码的时候不需要经过密码验证，而且可以无视密码策略
如果passwd后面什么都不接，默认是修改当前用户的密码
如果是普通用户修改密码，那么需要验证当前的密码才可以进行修改，并且不能无视密码策略
```

**`su`**：切换用户

```
1.格式:su-用户名
2.root用户可以不需要验证其他用户的密码直接登录
3.普通用户登录其他用户需要验证用户的密码
4.如果用户没有设置密码，是无法用普通用户切换过去的!
```

**`history`**：调用历史命令

```
1. !num  调用第num个条目的命令
2. !s  调用最近一条以s开头的命令
3. Alt + .调用上一个命令的最后一个参数
4. Ctrl + r 根据关键字搜索执行的命令
```

**tab键**：自动补全内容，可以是命令，可以是选项，也可以是参数。任何对象都可以补全

按一下'tab’，如果具有唯一性，可以直接补全
按2下'tab’，可以列出以改命令或者某个对象开头的内容

**使用图形化终端的一些快捷方式**

```
1快速的新建标签页:ctrl + shift + t
2删除标签页:ctrl + d (必须保证终端上没有任何的命令)
3 切换不同的标签页:alt + 1
4 扩大终端的字体:ctrl+shift +"+"
5 缩小终端的字体:ctrl+shift +"-"
```
